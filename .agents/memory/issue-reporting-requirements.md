---
name: Issue reporting requirements
description: User expectations for Report Issue diagnostics and the Admin issue/bug section
---

Report Issue submissions should be tracked in an Admin issue/bug section with the NetSuite case number and current case status, plus an image of the reporting page, its URL, and browser logs.

**Why:** The user requested that administrators can investigate reports with the original page context and track the corresponding NetSuite case.

**How to apply:** Keep diagnostics linked to the specific submitted report. Capture the reporter's actual page, not an anonymous server visit that would show the login page. Protect diagnostic images/logs as admin-only information and avoid exposing credentials or entered form values.

Only cases sent through Consumers Product Selector belong in the Admin section, not other NetSuite cases.

**Why:** The user explicitly clarified that the Admin section is limited to Consumers Product Selector submissions.

**How to apply:** Use the app's own report history as the source of the list; read NetSuite only to retrieve case numbers and statuses for those reports. Do not import unrelated cases.

Include the CPS Admin page URL in new NetSuite case information. Delete report screenshots after 12 months from the report creation date; retain the report and other diagnostics.

**Why:** The user requested a direct Admin link in case information and a 12-month image retention limit.

**How to apply:** Apply retention to existing and new report images, not only closed cases. Do not delete the NetSuite case or the CPS report record.
